# KVM Keyboard Support Fix: Implementation Plan (P0: WBS Compilation)

## Goal
To ensure seamless sharing of keyboard inputs between the Linux server and the macOS client in the KVM project.

## Problem Statement
Keyboard inputs are not being shared. Analysis indicates that the `kvm-server`'s device detection logic (`src/bin/server.rs:find_input_devices`) uses a strict heuristic (key count >= 30) to identify a keyboard device, which may be failing for certain modern or specialized keyboard peripherals.

## Scope
- **In Scope:** Modifying the device detection logic in `src/bin/server.rs` to correctly identify and initialize the keyboard input device.
- **Out of Scope:** Modifying the event serialization/deserialization in `src/lib.rs` or the event handling logic in the main loop, as those were found to be functionally correct.

## Implementation Details (TDD Focus)

**Component:** `find_input_devices` function in `src/bin/server.rs`.
**Target:** Improve `is_keyboard_candidate` determination.

**Hypothesis:** The key count heuristic is too brittle.
**Refinement:** Instead of relying on `key_count >= 30`, check for a combination of `EventType::KEY` support AND a name/vendor ID pattern that is highly indicative of a keyboard, while ensuring other common peripheral types (like trackpads or specialized mice) are excluded.
